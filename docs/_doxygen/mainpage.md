# ISF15ACP4 Driver API reference {#mainpage}

The classes, members and types of the HardFOC driver for the NKK ISF15ACP4 SmartDisplay OLED pushbutton, generated
from the headers.

Start with isf15acp4::SmartDisplay, the driver, and isf15acp4::SpiInterface, the interface your platform port
implements. Drawing goes through isf15acp4::GraphicsContext and isf15acp4::Canvas; timed frames through
isf15acp4::Animator; the switch through isf15acp4::ButtonUI. SSD1331 opcodes and the initialisation tables are in
the isf15acp4::ssd1331 namespace.

The guides, with examples that compile, are on the documentation site: <a href="../">ISF15ACP4 Driver
documentation</a>.
